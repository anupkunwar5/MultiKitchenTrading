# MultikitchenTrading

MultikitchenTrading is a dynamic and responsive e-commerce website developed for trading kitchen products and accessories. The website is built using Java, JSP, HTML, CSS, and other supporting technologies. It uses XAMPP as the backend environment, incorporating Apache and MySQL for local server and database management.

## Project Overview

MultikitchenTrading functions as a complete platform where users can browse, select, and manage kitchen-related items. The application supports both customer and admin roles, enabling secure logins, product management, and basic order handling.

## Technologies Used

 Frontend: HTML, CSS, JavaScript, JSP
 Backend: Java (Servlets, JSP)
 Database: MySQL
 Server Environment: Apache (via XAMPP)
 Development Tools: XAMPP, Eclipse or NetBeans IDE, JDBC

## Setup Instructions

1. Install XAMPP and start Apache and MySQL services.
2. Import the provided MySQL database into phpMyAdmin.
3. Copy the project folder into the `htdocs` directory of XAMPP.
4. Update the database connection settings in your Java configuration file.
5. Open the project in your IDE and run it on `localhost`.

## Features

 User registration and login
 Product display with image, description, and price
 Add to cart and checkout simulation
 Admin dashboard for product management
 MySQL-backed product and user data
 Basic session handling for user roles
